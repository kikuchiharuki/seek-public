# CSV整形ツール

配送依頼CSVを読み込んで整形・色付け・印刷用レイアウトに変換するWEBツール。
Excel VBAマクロ（アドイン用.txt）の置き換え。**index.html 1ファイルで動作**（ブラウザで開くだけ）。

## 使い方（Excelマクロと同じ流れ）

1. `index.html` をブラウザで開く（またはローカルサーバーで配信）
2. CSV / Excel ファイルをドラッグ&ドロップ → **元データがそのまま表示される**
   - **複数ファイル同時OK（最大5ファイル）**。ジェット形式とruum形式の混在も可
3. 「⚡ 変換する」ボタン → 整形・色付けされた結果が表示される
   - 変換後、元データは1行に折りたたまれる（「▸ 元データ」クリックで再表示）
   - 変換結果は同じ商品のファイルが隣り合うように並び替えられる
   - **セルはクリックして直接修正できる**（修正は集計バーにも反映）
4. 「📅 出荷日を設定」（Excel版の出荷日設定ボタン相当）
   - 出荷日は**自動入力されない**（当日出荷の場合もあるため）。日付を選んでボタンを押す
   - 福通リードタイムで着日を計算し、指定納期に間に合わない行は納期を着日に変更して**黄色表示**
   - 出荷日を変えて押し直すと元の納期を基準に再計算される（早めれば黄色が消える）
   - **このボタンを押すまで（出荷日セルが空白のままだと）Excel保存・送り状CSV・印刷はできない**
   - 保留・在庫切れなどで今回の出荷から外したい行は、行末の **🗑ボタンで削除**できる
     （確認ダイアログあり。再変換すると元に戻る）
5. 「🖨 印刷」 → A4横で印刷。出荷日と商品別集計が表の上に印刷される
   - 注記（ゆうパック件数など）は印刷されない
   - 印刷時はテーブル実幅からzoom倍率を自動計算して全列を1ページ幅に縮小
     （Excelの「すべての列を1ページに印刷」相当。beforeprint/afterprintで着脱）
6. 「📥 Excel保存」 → `YYYYMMDD出荷分商品名+商品名.xlsx`（日付は出荷日）で保存
   - 出荷日が未設定だと保存できない（ファイル名に使うため）
   - **画面の見た目をそのまま再現**: 背景色（赤/緑/ピンク/黄）・赤太字・会社名の改行
     （wrapText）・行の高さ・罫線・列幅付き（xlsx-js-style使用）
   - 複数ファイル時はファイル名区切り行入り。数量は数値として出力
7. 「🚚 送り状CSV」 → 福山通運の送り状発行ソフト取込用CSVの**プレビューが表示される**
   - **セルをクリックして手修正できる**。確認・修正してから「📥 CSVをダウンロード」で
     `◯月◯日出荷日分CSVエントリーデータ.csv`（日付は出荷日、Shift-JIS・CRLF）を保存
   - 出荷日が未設定だとプレビューを作れない（出荷日付・ファイル名に使うため）
   - **ゆうパック行は出力されない**（福通で送らないため。除外件数は注記に表示）
   - 荷送人コード・品名記事1～3は商品名からマスタ（CONFIGの`productMaster`）で自動設定。
     マスタ未登録の商品は注記で警告される（該当欄が空欄になるのでプレビューで手入力できる）
   - **ニオイしま栓！は2ケース1梱包ルールで送り状が自動分割される**
     （数量3 → 「2ケース1梱包」1件＋1ケース1件。数量5 → 梱包2件＋1ケース1件）
   - **必須項目（電話番号・住所・名前・郵便番号・荷送人コード・個数・配達指定日など）が
     空白の行があるとダウンロードできない**（該当セルが赤表示。プレビューで手入力すれば保存できる）
   - 詳細仕様・列マッピング・分割ルールは `docs/送り状CSV仕様.md`

列マッピングは裏でファイルごとに自動実行される。既知フォーマットなら何も操作不要。
自動認識できない列があるときだけマッピング編集画面が自動で開く
（「列マッピングを確認・編集」リンクからいつでも開ける。複数ファイル時はタブで切り替え）。

### 複数ファイルの扱い（VBA版 複数CSV対応 v1.8.2 と同等）

- 各ファイルは**個別に**変換処理される（重複統合・連番はファイル内で完結、ファイルをまたいで統合しない）
- 変換結果はファイルごとに区切り行付きで縦に並ぶ: `📄 ファイル名　データn件　個数合計n件`
  （**列名行はファイル名行の下**に、ファイルごとに繰り返し表示される。Excel保存も同じ並び）
- 番号はファイルごとに1から振り直し
- 商品別集計バーは全ファイル合算
- 上限ファイル数は `CONFIG.maxFiles`（既定: 5）

## 設定の場所

**すべての設定は `index.html` 内の `CONFIG` オブジェクトに集約**されている（`★★★ 設定データベース ★★★` で検索）。
新フォーマット・新製品・新ルールは原則そこだけ編集すればよい。

| セクション | 内容 | 編集するタイミング |
|---|---|---|
| ① outputColumns | 出力列の定義と順序 | 出力レイアウトを変えたいとき |
| ② columnAliases | 入力列名のエイリアス | **新フォーマットのCSVが来たとき** |
| ③ phonePriority | 電話番号の優先順位 | 電話番号列が増えたとき |
| ④ productRules | 製品ごとの特殊処理 | **新製品が追加されたとき** |
| ⑤ carrierRules | 運送会社の自動判定 | 配送ルールが変わったとき |
| ⑥ duplicateMergeKeys | 重複統合の判定キー | 統合条件を変えたいとき |
| ⑦ companyLineBreakMarkers | 会社名の改行位置（㈱+半角/全角スペース） | — |
| ⑧ colors / emptyCheckColumns | 色ルール | 色や対象列を変えたいとき |
| ⑨ leadTime | リードタイム納期チェックのON/OFF・祝日API | 配送ルールが変わったとき |
| ⑩ zipcode | 郵便番号自動取得のON/OFF・API | — |
| ⑪ invoiceCsv | 送り状CSVの列・製品マスタ（荷送人コード/品名記事/まとめ梱包）・固定値 | **新製品の追加時**・品名記事や荷送人コードの修正時・送り状ソフトの取込仕様変更時 |

※ リードタイムデータ本体は `LEADTIME` 定数（`~/seek-public/lead-time.html` 由来、約1500件）。
データ更新時は lead-time.html の `const D=` 行をコピーして差し替える（手編集しない）。

## 現在の設定内容（2026-06時点）

### 対応フォーマット

| 出力列 | ジェット形式 | ruum形式 |
|---|---|---|
| 商品 | 商品 | 商品名 |
| 数量 | 数量 | 数量 |
| 配送依頼日 | 配送依頼日 | 建物管理配送依頼日 |
| 指定納期 | 指定納期 | 指定納期 |
| 販売先会社名 | 販売先会社名 | 業者名 |
| 電話番号1 | 電話番号1 | （問合せ電話番号は空が多い→下記優先順位） |
| 郵便番号 | 郵便番号 | 郵便番号 |
| 都道府県 | 都道府県 | （住所から自動分割） |
| 市区町村郡町名番地 | 市区町村郡+町名+番地（結合） | 住所（都道府県を除去） |
| 建物名など | 建物名など | （なし→空白） |

※ 番号列は廃止（表の#列=行番号で代用）。出荷日・運送会社・重複は自動生成列。

### 電話番号の優先順位

`電話番号1` → `担当者連絡先番号`（担当者連絡先も可）→ `電話番号2` → `問合せ電話番号`

データが入っている最初のものを採用。無効値: `-` `--` `---` `なし` `無` `不明` 3文字未満。

### 処理パイプライン（実行順）

1. **空行除去** — 全列空白の行を削除（読み込み時）
2. **電話番号統合** — 上記優先順位で1本化
3. **住所結合/分割** — 3列分割形式は結合、1列結合形式は都道府県を分離
4. **郵便番号整形** — 7桁数字は `123-4567` 形式に
5. **運送会社判定** — 都道府県/住所に「沖縄」「那覇」→ ゆうパック
6. **重複統合** — 商品+指定納期+会社名+住所が全一致 → 数量合算、「重複」列に「数量合算」
7. **会社名処理** — ジェット系商品→「大東建託リーシング株式会社（改行）〇〇店」/ 「㈱ 」「㈱　」の後に改行
8. **郵便番号自動取得** — 郵便番号が空白の行は HeartRails Geo API で住所から取得（順次・150ms間隔）。
   それでも埋まらなかった行は郵便番号セルが赤になる
9. **出荷日設定+納期チェック**（「出荷日を設定」ボタンで実行）— 福通リードタイムで着日を計算し、
   指定納期に間に合わない行は納期を着日に変更して**黄色表示**（セルにマウスを乗せると元の納期を表示）。
   ゆうパック行は対象外。祝日は holidays-jp API（オフライン時はルール計算）。何度でも再実行可

### 色ルール

| 条件 | 色 |
|---|---|
| 必須セルが空白（商品/配送依頼日/指定納期/会社名/電話番号1/都道府県/郵便番号/市区町村郡町名番地） | 赤 `#ff5d5d` |
| 数量が空白または0 | 赤 `#ff5d5d` |
| 数量2以上 | 緑 `#ccffcc` + 太字 |
| ゆうパックの行全体 | ピンク `#ffccff` |
| ゆうパックの文字 | 赤太字 |
| リードタイム的に間に合わず納期を変更したセル | 黄 `#ffff00` + 太字 |

### 製品ルール

| 商品名 | 処理 |
|---|---|
| ジェット＆ビーズ / ジェット＆ディフューザー | 会社名を「大東建託リーシング株式会社（改行）元の会社名+店」に変換（変換済みならスキップ） |

## 技術構成

- 単一HTMLファイル（ビルド不要・ポータブル）
- [PapaParse](https://www.papaparse.com/) — CSV解析（CDN）
- [xlsx-js-style](https://github.com/gitbrent/xlsx-js-style) — Excel読み書き+スタイル出力（CDN、SheetJS 0.18.5互換）
- [encoding-japanese](https://github.com/polygonplanet/encoding.js) — 送り状CSVのShift-JIS出力（CDN）
- 文字コード: UTF-8 / Shift-JIS (CP932) 自動判定（CSVはどちらでも読める）
- Excel読込時は日付セル（シリアル値）を `2026/6/8` 形式に自動変換
