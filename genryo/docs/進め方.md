## デモの台本（案）

1. 原料マスタのExcelをそのまま取り込む（列の当てはめ → 確認 → 取込）
2. フコイダン保湿ローションの処方を開く → 原料費/kgがその場で出る
3. 原料を1つ値上げ → どの製品にいくら響くかが出る
4. 100kg製造を登録 → 原料と容器の在庫が減る
5. 棚卸で実数を入れる → 差が自動で合う
6. 見積書を出す → 値上げ前の単価で固定されている
