# デザインの土台

**下敷き：デジタル庁デザインシステム（DADS）**。値は公式データをそのまま使う。
- 出典：`@digital-go-jp/design-tokens` 2.0.1、`digital-go-jp/design-system-example-components-html`（どちらも MIT License / © デジタル庁）
- 実装：`css/dads.css`　見本：`design-sample.html`（品目一覧＋詳細パネル）

## DADSのまま使うもの

| 項目 | 値 |
|---|---|
| 文字 | Noto Sans JP。本文16px・行間1.7・字間0.02em。見出し28/20/17px太字 |
| 色 | キーカラー青 `#0017C1`（押下時 `#00118F`→`#000060`）。本文 `#333`、補足 `#767676`（白地で読みやすさの基準AAを満たす） |
| 注意の色 | エラー赤 `#EC0000`、警告 黄 `#927200`／橙 `#C74700`、成功 緑 `#197A4B` |
| ボタン | 塗り／線／文字の3種。高さ48・36・28px、角丸8・6・4px。マウスを乗せると下線 |
| 入力欄 | 枠 `#666`・角丸8px・高さ48／40px。マウスを乗せると枠が黒 |
| フォーカス | 黒4pxの枠＋黄色の縁取り（キーボード操作でどこにいるか一目で分かる、DADSの特徴） |
| 表 | 見出し行は灰色地＋下に黒線、行を指すと薄い青 |
| ラベル | 角丸8px（丸くしすぎない）。枠線＋淡い地＋濃い文字 |
| お知らせ | 左に太い色帯＋枠線 |

## 業務画面向けに変えたところ（★調整）

| 項目 | DADS | このアプリ | 理由 |
|---|---|---|---|
| 表の文字・余白 | 16px・上下12px | 14px・上下10px | 1000件超の原料を一覧で見るため |
| 表の中のラベル | 16px・高さ32px | 14px・高さ24px | 行の高さをそろえるため |
| お知らせの余白 | 24〜40px | 12〜24px | 画面上部を占領しないため |
| 絞り込みの切替 | 該当部品なし | 線ボタン小＋押下中は塗り | |

## 画面の型

- 上：アプリ名・開いているファイル・未保存の件数・保存
- 左：メニュー（品目／処方／製造／在庫／見積 ＋ 取込／取引先）。今いる画面は左に青い帯
- 中央：一覧（検索・区分・状態で絞り込み）
- 右：選んだ行の詳細パネル。一覧から離れずに見て、編集は別画面

## 使わないもの

クリーム色の背景、見出しの斜体強調、01/02/03の番号ラベル、等幅フォントのラベル、ピル型（丸すぎる）ボタン、グラデーション、絵文字アイコン、影の強いカードの並べすぎ、**同じ意味のラベルの重ね付け**（在庫少は在庫数を赤で示せば足りる）。

画面を見て「AIっぽい」と感じたものは、ここに足していく。
