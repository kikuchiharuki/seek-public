2色 / Colours

写真から目立つ色をそのまま選びます。イラスト向き。
レーザー加工機用。元画像のフル解像度で処理して、白黒PNG/JPEGを保存します（3D化はしません）。 線画＝線だけ黒。写真（点描）＝濃淡を細かい点の密度で表す（Floyd–Steinbergディザ）。白黒2値＝明るさで白黒に分ける（ステンシル向き）。 しきい値0は自動。途切れ補修は線の小さな切れ目をつなぎます（元画像のピクセル単位）。
線のわずかな切れ目（この長さ以下）をつないで閉じます。3Dプリントで色が漏れないように。 線画モードでは「きめ細かさ」を800px以上にするのがおすすめ。線画は軽いので重くなりません。
線画（マンガ・線だけのイラスト）専用。元画像のフル解像度で線を拾います。 「線の太さ」は最低保証で、元の線がそれより細いときだけ太らせます（元のままなら0）。 小さく印刷して線が0.4mm未満になるときは 0.5〜0.6mm にしてください。 しきい値0は自動（大津法）。薄い線が拾えないときは上げてください。
小さな点や模様を掃除して、色のかたまりを大きくします。3Dプリント向き。
Cleans up speckle so each colour is one solid region.
画像の縁からつながった色だけを抜きます。絵の中の白目などは残ります。
使っている色の中から一番暗い色を自動で選び、色の境目に線を引きます。 減色で消えてしまった線画を復活させたいときに。
Draws a line along every colour boundary using the darkest colour in the palette.

3立体にする / Make it 3D

背景の中に浮いている、この面積未満のゴミを消します。 絵の中の小さな点（目のハイライトなど）は消えません。0で無効。
「なめらか」は色の境目をドットの階段ではなく、曲線でつないで押し出します。 線画や丸い形がきれいになります。三角形数はほぼ同じか少し減ります。
スライサーのバケツ塗りは面の角度で塗る範囲を決めます。 ごく小さな段差でも90°の角ができるので、そこで塗りが止まります。 積層の厚みよりずっと小さいので、印刷結果には現れません。
0.0001〜0.4mm で試して、確実に効く一番小さい値を見つけてください。 0にすると完全にフラット（塗り分けは効かなくなります）。
奥行きを出したいときに。レリーフや小物にも使えます。
小物に貼るときは実寸で書き出してください。スライサーで縮小すると厚みまで縮んで1層に満たなくなります。
Export at final size — scaling in the slicer shrinks the thickness too.
「絵を下」は、絵の面をビルドプレートに向けて印刷する用。 土台とキーホルダー穴が絵と同じ面まで伸びるので、浮く部分がありません。 絵は自動で左右反転され、印刷面で正しい向きになります。 書き出したらそのまま印刷してください（反転・沈める操作は不要）。
土台の縁に沿って穴の位置を動かせます。3Dプレビュー上で穴をドラッグしても動きます。 「つけ根の補強」は輪と土台のあいだを両側からなだらかに埋める丸み（フィレット）の大きさ。 大きいほど折れにくくなります。四角・丸・縁沿い、どの土台でも同じ形に付きます。
別のモデルの面に貼る（めり込ませる）用。各色を裏側へこの分だけ延長します。 スライサーで本体に「パーツを追加」して沈めても、絵と本体の間に隙間ができません。
Extends every colour downwards so the art can sink into another model with no gap. In Bambu / Orca, add the colour files as parts of the same object — parts may overlap freely; separate objects may not.
